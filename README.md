# SQA Assignment 2 - Playwright Automation

## Project Overview

This project contains automated end-to-end tests for the Tricentis Demo Web Shop using Playwright with TypeScript.

The project covers three automation tasks:

- Q1: Invalid Login
- Q2: Register and Add Product to Cart
- Q3: Product Search and Cart Verification

## Technology Stack

- Playwright
- TypeScript
- Node.js
- Git
- GitHub
- Allure Report
